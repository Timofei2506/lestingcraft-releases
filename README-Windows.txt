LESTINGCRAFT: NEW ERA — WINDOWS x64
Версия: 0.3.0-living-test, открытая тестовая сборка, 16.10.2026.

ЗАПУСК
1. Скачайте LestingCraft-Windows-x64-0.3.0-living-test.zip.
2. Распакуйте ВЕСЬ архив в отдельную папку. Не запускайте EXE прямо из ZIP.
3. Откройте LestingCraft.exe. Unity, Hub и SDK устанавливать не нужно.
4. Для первого знакомства выберите одиночное выживание или творческий режим.

Платформа: Windows 10/11 x64, совместимая с Direct3D 11 видеокарта. Это не
Android-версия. Точные минимальные требования и FPS пока не установлены.
Нужно около 660 МБ для распакованных игровых файлов и дополнительное место
для архива и сохранений. Medium — уже детальная графика, Ultra значительно
тяжелее. Аппаратный RTX не реализован.

КООПЕРАТИВ И АККАУНТ
Создать Multiplayer → дождаться друзей в лобби → запуск хозяином.
Поддерживается 2–8 игроков; полноценный длительный тест восьмерых пока не
проведён. Бесплатный сервер имеет лимиты; возможна временная недоступность.
Играть одному можно без аккаунта. Аккаунт: логин/пароль, без почты; сохраните
код восстановления в безопасном месте и никому его не сообщайте. Статистика
для локальной игры/друзей, не соревновательная античит-система.

СОСТОЯНИЕ ВЕРСИИ
Это тест, а не законченная игра. Реализована первая глава; остальные четыре
сюжетные главы ещё не готовы. Вступление в разрушенном доме обязательно
для новых нетворческих миров; дальше историю можно продолжать без спешки.
Старые ландшафты не принудительно переводятся на новую генерацию. Перед
проверкой старых сохранений рекомендуем сделать их резервную копию.

Windows EXE действительно собран и запущен в облаке: меню, вступление, мир,
инвентарь/броня, крафт 2×2/3×3, печь, SSAO и SSR прошли автоматические проверки.
WARP — программная графика тестового сервера, не FPS-бенчмарк вашего GPU.
Отдельная цифровая подпись издателя для этой тестовой сборки не оформлялась.
Контрольные суммы опубликованы в SHA256SUMS.txt. Не отключайте защиту ПК.
