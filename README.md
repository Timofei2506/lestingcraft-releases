### В этом патче
Разные позы/облик персонажей вступления; окно обмена с жителем по ПКМ и отдельным подтверждением; полный творческий каталог 98 предметов с поиском/категориями/хотбаром; заметное прозрачное стекло; шесть типов биомов в новых мирах. Старые сохранения, включая неисследованные участки, остаются на прежней генерации. Подробности и управление — README-Windows.txt / CHANGELOG.md.

Windows EXE действительно запущен в облаке; 11 PNG — реальные кадры без рисования/ретуши. Торговец/стеклянное окно добавлены как явные внутриигровые проверочные объекты, дюны генерирует сама игра. WARP — программный рендерер, не FPS-тест вашего GPU. Диагностические цветовые маски не входят в игровую галерею или ZIP.

Остальные четыре сюжетные главы не завершены; кооператив 2–8 без длительного стресс-теста восьмерых; бесплатный сервер может достигать лимитов; аппаратный RTX отсутствует. Перед запуском старых сохранений сделайте резервную копию.

Сборка без отдельной подписи издателя. Не отключайте защиту ПК; проверяйте SHA256SUMS.txt. Не публикуйте пароли, коды восстановления, токены или личные сохранения. Старые тестовые версии оставлены в истории релизов.


Скриншоты не публикуются. Ранее размещённые папки изображений удалены из текущей публичной ветки по просьбе автора. Игровые сборки оставлены. Старые Git-коммиты/кеши этим изменением не переписываются.
